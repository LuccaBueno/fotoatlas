# fotoatlas_core

Núcleo do FotoAtlas em Dart puro (sem Flutter): catálogo SQLite, fontes, escaneamento e, nas próximas fases, hash, cobertura e cópia segura. Inclui a CLI `fotoatlas_cli`.

```powershell
dart pub get; dart analyze; dart test
dart run bin/fotoatlas_cli.dart --help
```

Veja `docs/arquitetura.md` na raiz do repositório.
