# Como usar com o Claude Code

Abra o PowerShell:

```powershell
cd C:\dev\fotoatlas
claude
```

Comandos curtos que bastam (o Claude Code lê o `CLAUDE.md` e o `docs/ROADMAP.md` sozinho):

| Você digita | O que acontece |
|---|---|
| `comece` | Faz a Etapa 0 (planejamento) e para para sua aprovação |
| `aprovado` | Começa a fase seguinte |
| `continue` | Retoma de onde parou |
| `pode seguir direto` | Faz as fases sem pedir aprovação a cada uma |
| `status` | Resume o ROADMAP: feito, em andamento, próximo |
| descreva um problema | Ele corrige, testa e faz commit |

Dica: comece cada sessão nova com `continue`.
